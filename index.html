SokoPay ni nini?

SokoPay ni mfumo rahisi wa ulinzi wa malipo (escrow). Pesa ya mnunuzi inashikiliwa salama hadi mnunuzi athibitishe kupokea bidhaa/huduma — ndipo pesa inatumwa kwa muuzaji.

Jinsi inavyofanya kazi (hatua 5)
1. PAY — mnunuzi analipa kwa M-Pesa/Airtel/Tigo/Kadi. 2. SECURE — pesa inafungwa kwenye escrow (haiko kwa muuzaji wala mnunuzi). 3. TRACK — fuatilia kwa token yako (mf. SP-82KF91). 4. CONFIRM — mnunuzi anathibitisha mapokezi. 5. RELEASE / DISPUTE — pesa inatumwa kwa muuzaji, au mgogoro unafunguliwa.
Kuhusu Token

Token (mf. SP-82KF91) ni namba ya utambulisho wa muamala — si pesa yenyewe. Inatumika kufuatilia mchakato mzima.

Usalama

Browser haithibitishi malipo — server ndiyo mamlaka ya kila mabadiliko ya fedha (paid, released, refunded). Ukiona jambo lisilo la kawaida, fungua Dispute.
